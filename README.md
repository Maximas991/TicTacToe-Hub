# 🎮 TicTacToe-Hub

A modern, responsive Tic-Tac-Toe platform built with **PHP**, **HTML**, **CSS**, and **JavaScript**.  
Designed as a clean, interactive project for learning, practicing, and showcasing web development skills.

---

## 🚀 Features


### 👤 User System
- Login & logout
- Profile page
- Persistent user data (depending on your setup)

### 🏆 Leaderboard
- Tracks wins, losses, and draws
- Displays top players
- Updates automatically

### 📱 Fully Responsive Header
- Desktop navigation
- Mobile hamburger menu (CSS checkbox toggle instead of java)
- Smooth slide-in mobile menu
- Logo hover animation

### 🧩 Core Gameplay (Coming Soon)
- Play classic Tic-Tac-Toe in the browser
- Clean UI with smooth animations
- Instant win/draw detection
- Replay without refreshing the page

## 📦 Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Maximas991/TicTacToe-Hub.git
```

### 2️⃣ Move the project into your XAMPP htdocs folder

```
C:/xampp/htdocs/TicTacToe-Hub/
```

### 3️⃣ Start Apache in XAMPP

Then open:

```
http://localhost/TicTacToe-Hub/
```
